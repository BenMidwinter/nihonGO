# nihonGO!

Mobile practice hub for Japanese drills.

**Live:** https://benmidwinter.github.io/nihonGO/

Add that URL to your Home Screen for quick access on your phone.

## Apps

| Path | Status |
|------|--------|
| [`/`](./index.html) | Home hub |
| [`/kana/`](./kana/) | Hiragana & katakana flashcards |
| [`/kanji/`](./kanji/) | Travel & daily-life kanji (test + revision) |
| [`/phrases/`](./phrases/) | Placeholder for common phrases |

## Local preview

```bash
python3 -m http.server 8765
```

Open `http://localhost:8765`.
